# Code of Conduct

## Our Standard

Nexus is built on the idea that **behavior should be verifiable, not promised**. We apply the same principle to this community.

We commit to making participation in this project a harassment-free experience for everyone, regardless of background, identity, or experience level.

## Expected Behavior

- Critique code and ideas, not people
- Assume good faith; ask clarifying questions before assigning bad intent
- When you disagree, explain why with specifics — invariants, tests, or examples
- Credit prior work; cite sources
- Help newcomers find the open layer (`agents/`, `docs/`, `nexus/api/`) before touching core

## Unacceptable Behavior

- Personal attacks, insults, or harassment of any kind
- Public or private harassment, including unwanted sexual attention
- Publishing others' private information without explicit permission
- Sustained disruption of discussions or reviews
- Other conduct that would reasonably be considered inappropriate in a professional setting

## Scope

This Code applies in all project spaces — issues, pull requests, commit messages, code comments, discussions, and any project-related communication channels — and also when an individual is representing the project in public.

## Enforcement

Reports of unacceptable behavior may be sent to **tim@timmeck.dev**.

All reports will be reviewed and investigated promptly and fairly. The maintainers are obligated to respect the privacy and security of the reporter.

Consequences may include:

1. **Correction** — a private written warning, clarifying the violation
2. **Warning** — a public note, with a temporary restriction on interactions
3. **Temporary ban** — no interaction with the project for a defined period
4. **Permanent ban** — for sustained or severe violations
